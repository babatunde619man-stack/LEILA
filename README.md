SphereBot - refactor (slash commands)
------------------------------------
Instructions:
1. Put your bot token in .env (BOT_TOKEN=your_token). Optionally set GUILD_ID to test fast.
2. Create a venv, install requirements: pip install -r requirements.txt
3. Run: python bot.py
Notes:
- This project uses discord.py v2 app_commands for slash commands.
- Do NOT commit your token. Rotate token if it was leaked.
